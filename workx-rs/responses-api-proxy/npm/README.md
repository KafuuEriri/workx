# @ronanxiao/workx-responses-api-proxy

<p align="center"><code>npm i -g @ronanxiao/workx-responses-api-proxy</code> to install <code>workx-responses-api-proxy</code></p>

This package distributes the prebuilt [Workx Responses API proxy binary](https://github.com/RonanXiao/workx/tree/main/workx-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/workx-responses-api-proxy.js --help
```

Refer to [`workx-rs/responses-api-proxy/README.md`](https://github.com/RonanXiao/workx/blob/main/workx-rs/responses-api-proxy/README.md) for detailed documentation.
